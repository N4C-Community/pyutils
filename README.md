## Prerequisites

- Python v3.14+
- pip v26.1+
- git v2.54+

## Installation
### Source Code
```bash
git clone https://github.com/N4C-Community/pyutils.git
cd ./pyutils
python -m venv .venv

# using venv
source .venv/bin/activate   # if your using linux
.\.venv\Scripts\activate.bat    # if your using cmd
.\.venv\Scripts\Activate.ps1    # if your using powershell / powershell7

pip install -r requirements.txt
```

### PIP Package
```bash
pip install pyutils-n4c
```

## Optional Usage (for development)

```bash
python dev.py   # You must first create a file in the project root!
```
